
# HeadBallAbdulla

HeadBallAbdulla (kickdulla) is a 2D football game created by Alvin Antony Ajish based on Abdulla Arshawin Shameer (boxing champion).

## About

HeadBallAbdulla focused on visual interactive gameplay as head of Abdulla with Kratos,Alin Jose and Santhosh Varkey. Who reach 10 goals in one gameplay would win.

## Features

- Fully free and playable in browser.
- Solo developer.
- Browser data Saving Available.

## Tech Stack

- Godot 4 Moblie
- GDScript
- AI Assisted

## Getting Started

### Requirements

- Mobile/PC
- Compatible Browser (Blink, Gecko, Webkit tested)
- Newer Hardware

### How To Play

1. Enter this Domain:

   alvin-antony-ajish.github.io/HeadBallAbdulla

2. Click Full screen.

3. Click Launch Game.

4. Click Start Game.

5. Enjoy!
